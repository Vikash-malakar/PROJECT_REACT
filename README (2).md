# Admission Enquiry System - Frontend

This is the modern, responsive single-page frontend built with React, Vite, Tailwind CSS, and Framer Motion for smooth animations and a non-scrollable, immersive user experience.

## Features
* **Interactive 3D UI:** Powered by Framer Motion spring physics and mouse-tracking effects.
* **Multi-Step Form:** Clean separation for Personal Info, Academic Details, and Submission.
* **Fully Responsive & Non-Scrollable:** Optimized layout ensuring zero vertical overflow across all screen sizes.
* **Custom Branding:** Integrated dynamic branding with smooth rotation animations.

## Prerequisites
Make sure you have **Node.js** (v16 or higher) installed on your system.
